# Tintype on AWS (reference deployment)

This module creates:
- **Network:** a VPC (2 AZs, one NAT gateway) and an ALB (HTTPS, websockets for Reverb).
- **ECS Fargate services:**
  - `web` (FrankenPHP + a Reverb sidecar), `horizon` and `scheduler`;
  - one `capture-<browser>` service per browser, autoscaled on the number of
    queued capture shards per worker.
- **Data:** RDS Postgres 16 and ElastiCache Redis.
- **Storage:** a private, encrypted S3 bucket.
- **Secrets:** generated by the module and kept in Secrets Manager.

Capture workers run on `X86_64` (baselines must come from x86_64). They have no
IAM permissions and can't reach the database or Redis. They only talk to the
web service, over the private service-discovery name.

```hcl
module "tintype" {
  source          = "github.com/kevin-coyle/tintype//deploy/terraform/aws"
  region          = "us-east-1"
  domain_name     = "tintype.example.com"
  certificate_arn = "arn:aws:acm:us-east-1:123456789012:certificate/…"
  capture_images = {
    chromium = "ghcr.io/kevin-coyle/tintype-capture-chromium:latest"
    firefox  = "ghcr.io/kevin-coyle/tintype-capture-firefox:latest"
  }
}
```

After `terraform apply`:
1. Point `domain_name` at the `alb_dns_name` output.
2. Open `https://<domain>`. The first account you register becomes the admin.
3. In **Admin → GitHub App**, create the app and install it on your
   repositories.
4. Create a project and add its token to CI as `TINTYPE_PROJECT_TOKEN`.

Pin image tags (`:sha-…`) in production. Bump the capture image deliberately,
because a new browser version changes pixels.
